# Changelog

Все значимые изменения в проекте будут документированы в этом файле.

## [Unreleased] - Исправления багов и улучшения

### 🚨 Критические исправления

#### Исправлено
- **Неправильная обработка исключений в main.py**
  - Исправлена грамматическая ошибка: "excepted" → "expected"
  - Заменен слишком широкий `except Exception` на конкретные исключения
  - Добавлено логирование stack trace с `exc_info=True`
  - Добавлена обработка `KeyboardInterrupt`

- **Memory leaks в OverlayUI.py**
  - Добавлены ограничения на количество объектов (MAX_OBJECTS = 1000)
  - Добавлены ограничения на количество таймеров (MAX_TIMED_EVENTS = 100)
  - Улучшена обработка ошибок в событиях таймера
  - Оптимизирована отрисовка только видимых объектов

- **Потенциальный deadlock в ThaumInteractor.py**
  - Добавлена защита от бесконечной рекурсии (MAX_RECURSION_DEPTH = 20)
  - Улучшена обработка ошибок в методе `mixAspect`
  - Добавлены проверки на None для счетчиков аспектов

- **Неправильное управление ресурсами**
  - Исправлена загрузка изображений с proper resource management
  - Добавлены контекстные менеджеры для работы с файлами
  - Улучшена обработка ошибок при загрузке изображений

### ⚠️ Серьезные улучшения

#### Добавлено
- **Валидация входных данных**
  - Добавлены type hints для функции `distance`
  - Добавлена проверка типов координат
  - Улучшена обработка некорректных входных данных

- **Безопасная работа с файлами**
  - Атомарное сохранение JSON конфигураций через временные файлы
  - Улучшенная обработка ошибок JSON (FileNotFoundError, JSONDecodeError)
  - Добавлена поддержка UTF-8 кодировки

- **Новые утилиты безопасности**
  - `src/utils/safe_operations.py` - модуль безопасных операций
  - `src/utils/image_cache.py` - кэширование изображений
  - Добавлен RateLimiter для ограничения частоты операций

### 🔧 Улучшения производительности

#### Добавлено
- **Кэширование изображений**
  - LRU кэш для загруженных изображений
  - Уменьшение количества обращений к файловой системе
  - Оптимизация использования памяти

- **Оптимизация UI**
  - Отрисовка только видимых объектов
